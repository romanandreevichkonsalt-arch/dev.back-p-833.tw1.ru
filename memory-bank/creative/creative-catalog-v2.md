## Иерархия

```
catalog_collections          — коллекция каталога (Онли, Данель…)
  └── catalog_models         — модель (прямой диван, кресло…)
        ├── type_id          — тип изделия
        ├── габариты, материалы, описание (без шаблонов/стандартов)
        ├── галерея фото/видео модели (ракурсы)
        ├── catalog_model_prices — 8 строк: category 1…8 → price
        └── M:N → fabric_collections (фактуры)

fabric_collections           — фактура (= коллекция ткани, переименовать UI)
  └── fabric_colors          — цвет + category (1–8) + стоимость пог. м + образцы

catalog_products             — SEO-карточка = модель + цвет
        ├── model_id
        ├── fabric_color_id
        ├── price            — из model_prices[color.category]
        ├── main_image_id    — главное фото в интерьере (на каждый цвет)
        ├── slug, title, href
```

## Генерация товаров

При сохранении модели или при добавлении фактуры к модели:

- Для каждой связанной **фактуры** × каждый **цвет** в фактуре → **один товар**
- Пример: 2 фактуры × 8 цветов = **16 товаров**
- Цена товара: `model.prices[fabric_color.category]` (категория 1–8)
- Главное фото: на товаре (по цвету), галерея ракурсов — на модели

## Библиотека тканей (сайт)

Информационный раздел: фактуры и цвета, без отдельной покупки. Данные из `fabric_collections` + `fabric_colors`.
