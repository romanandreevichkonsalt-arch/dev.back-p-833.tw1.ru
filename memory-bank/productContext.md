# Product Context

## Зачем существует проект
Backend для приложения «Фабрика» — предоставляет клиентам (мобильное/веб-приложение) единую точку входа для регистрации, авторизации и получения данных профиля пользователя.

## Пользователи
- **Конечные пользователи** — входят по телефону (SMS) или через Яндекс ID
- **Администраторы** — работают через веб-модуль `/admin` (сессионная авторизация Yii2)

## Основные сценарии

### 1. Вход по телефону
1. Клиент отправляет `POST /api/v1/auth/request-code` с номером телефона
2. Сервер создаёт пользователя (если новый), генерирует 6-значный код (TTL 5 мин)
3. Код «отправляется» через SMS-заглушку (в dev возвращается в ответе)
4. Клиент отправляет `POST /api/v1/auth/verify-code` с телефоном и кодом
5. Сервер выдаёт Bearer-токен (TTL 30 дней)

### 2. Вход через Яндекс ID
1. Клиент получает OAuth access_token на стороне Яндекса
2. Отправляет `POST /api/v1/auth/yandex` с `access_token`
3. Сервер запрашивает профиль у `login.yandex.ru/info`
4. Создаёт/находит пользователя, сохраняет `external_identities` и `user_profiles`
5. Выдаёт Bearer-токен

### 3. Профиль
- `GET /api/v1/profile/me` — данные текущего пользователя (требует Bearer)

## UX-ожидания API
- Все ответы в JSON
- Ошибки: HTTP 400 (валидация), 401 (авторизация)
- Телефон строго: `7` + 10 цифр
- Код SMS: 6 цифр
