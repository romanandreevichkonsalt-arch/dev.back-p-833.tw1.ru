# Project Brief

## Название
**Fabrika API** — backend-сервис проекта «Фабрика».

## Цель
REST API на Yii2 для мобильного/веб-клиента: аутентификация пользователей, управление профилем, административный модуль.

## Ключевые требования
- Stateless JSON API (Bearer-токены), отдельно от сессионной веб-части
- Вход по SMS-коду (телефон в формате `7XXXXXXXXXX`)
- Вход через Яндекс ID (OAuth access_token)
- OpenAPI/Swagger-документация
- CORS для кросс-доменных запросов
- Модуль `admin` с сессионной авторизацией (Yii2 web)

## Ограничения
- Стек: PHP (Yii2) + JavaScript (только по запросу)
- SMS-отправка через заглушку (`SmsSenderStub`) — реальный провайдер не подключён
- База данных: MySQL

## Статус
Базовая инфраструктура и auth-эндпоинты реализованы. Активных задач нет.
